# Omni 1.1 video editing, compared

Flow can edit an existing clip: click it in the project and use the "Describe how to edit this
video" box, which runs Omni 1.1 Flash. On 23 Sep 2026 it was asked to add this exact card style to
the same 10 s studio clip.

| | Omni 1.1 edit | kinetic-type (Tesseract) |
|---|---|---|
| Spelling | all correct | all correct |
| Look | bigger, glowier, letters arc in on a curve | clean, reference-faithful |
| Placement | over the hair and forehead | the navy band above the head |
| Timing | ran ahead of the speech (the big line was up while "they are posting" was still being said) | word-synced to the waveform |
| After the fact | baked in: no retiming, no moving, no fixing a word | any word, any time |
| Cost | ~40 credits per 10 s | free |

Hanif chose the Tesseract version. Omni is worth reaching for when the text itself should behave
physically in the scene (wrapping round an object, reacting to a hand); for a narrator's cards,
the two things you cannot fix afterwards — text on the face and text out of sync — both go to Omni.

The prompt that got the good spelling: name every string in quotes, say "spell every word exactly
as written", describe where the empty space is, and end with "no other graphics, no captions".
